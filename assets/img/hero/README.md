# Hero carousel photos

Drop 3–6 landscape photos here named **hero-1.jpg, hero-2.jpg, …** (jpg/png/webp all fine — keep the `.jpg` name or update `index.html`).

Suggested subject: diverse people automating / running code (e.g. engineers at workstations).
Recommended: ~1200×900 (4:3), optimized/compressed, and images you are licensed to use.

The site auto-detects `hero-1.jpg`: if present, the hero shows a cycling photo carousel; if absent, it shows the automation-workflow panel. No code change needed.
